# config-artifact

One visual for the whole flow — X-Bionic's team → the configuration Thoughtform
builds inside it → the Claude Enterprise agents and models (and Shopify,
analytics) the company already runs — in five permutations, each with a
section-1 frame (where it plugs in) and a section-2 frame (adoption becomes
automation). Lab: `/test/config-artifact?p=1..5&f=1|2`.

`iso/` is vendored from [anatomy](https://github.com/wheresryan22/anatomy)
(MIT, see `iso/LICENSE`): `iso-kit.ts`, `iso.css` and `react/`. Keep it
byte-for-byte so it can be refreshed from upstream; theme it from `ca.css`.
