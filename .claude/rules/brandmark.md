# Rule: Brandmark / sigil choreography

Edits here move a brandmark actor across fixed, projected, or in-canvas renderers. Small measurement mistakes show up as hero flashes, between-section float, practice snaps, or a visible SVG-to-particle size jump.

**Read first**

- [ADR-010: Brandmark choreography](../sentinel/decisions/010-brandmark-choreography.md)
- [ADR-023: Corridor Brandmark Physics Core](../sentinel/decisions/023-corridor-brandmark-physics-core.md)
- `.claude/skills/brandmark-choreography/SKILL.md` (checklist + Playwright recipe)
- Related stack: [ADR-008](../sentinel/decisions/008-landing-v7-background-layers.md) (layers)

**Process:** [sentinel/MAINTENANCE.md](../sentinel/MAINTENANCE.md) - run Cycle A after changing triggers; prefer live rects and `onLeave` settlement over new CSS sticky hacks.

**Home-v2 corridor invariant (REWRITTEN 2026-06-25 hybrid):** the live corridor brandmark is **two painters with an invisible seam**, not one. `ProjectedBrandmarkActor` owns the visible mark at full opacity (instant `display: block`, never an opacity fade) while corridor `progress < BRANDMARK_CORE_HANDOFF_PROGRESS` (`= CORRIDOR_TIMELINE.brandmark.thoughtformHold`, currently `0.14` — pulled earlier than the old `0.30` substrate-wrap anchor to give the morph more runway). The instant `progress` crosses that threshold from below, the SVG cuts to `display: none` in the SAME frame that `BrandmarkPhysicsCoreActor` rasterises the SVG's live screen rect (via `rasterizeBrandmarkToWorldPositions` + `worldPositionsToLocal` + `sim.reseed`/`sim.setHomePositions`) into world positions that reproject to those exact CSS pixels — so the eye sees no swap because the particles ARE the SVG at frame N+1. The two painters share a `brandmarkScreenRectRef` (`components/landing/home-v2/brandmarkScreenRectRef.ts`) — the SVG writes its rect every paint frame; the physics-core actor reads it at the swap frame. From there the vertex shader interpolates each particle from its matched-pixel seed to its paired `aTarget3D` (the GLB volumetric wireframe sampled from `/models/brandmark/brandmark.glb` via `sampleBrandmark3D` — the SAME mesh the #services hologram uses) with per-particle staggered `flowT`, +Z recede peaking mid-flow, and low-amplitude XY drift. By `uDepth = 1` (at substrate wrap peak, `progress = 0.42`) every particle has settled exactly on its wireframe home inside the substrate sphere. Pitfalls: cross-fading SVG and particles together (any non-zero opacity overlap reads as the dissolve the user explicitly rejected); using opacity instead of `display: none` for the SVG cut; using a synthetic dome bulge as the morph endpoint instead of `sampleBrandmark3D.armHomes`; making the particles try to look exactly like the SVG at rest (perceptually impossible at corridor density — five revisions tried, all failed; that's why the SVG owns the rest now); lowering `ignite` to create a swirl. The sim stays assembled (`seedAtHome`, `ignite=1`); the render shader owns the wind-blown flat → wireframe interpolation. ADR-023 Invariants 13–14 are the load-bearing contract.

**Harmonization (2026-06-25 follow-up):** the SETTLED in-sphere mark reads as a crisp, airy, Services-colored wireframe so the corridor→Services transition is continuation, not a swap. A `wireCrisp = smoothstep(0.7, 1.0, uDepth)` factor (vertex→`vWireCrisp`) tightens the dots + stills twinkle + shrinks specks + lerps body/accent from the flat-rest SVG gold (`#caa554`/`#e9c97a`) toward the #services palette (`uLandedColor`/`uLandedAccent` = `#b08b42`/`#dcc176`), plus a settled additive-alpha trim. `wireCrisp = 0` at the flat rest + flight, so the matched-pixel handoff stays color-seamless and the fly-in keeps its luminous warmth. Production #services is FRONTAL (`restTilt 0/0` in `ServicesStage.tsx`) to match the head-on in-sphere mark — keep both frontal (the sphere's sword↔vertical-orbit alignment depends on a frontal mark). Pitfalls: shifting the flat-rest color off `#caa554` (handoff pops); ramping `wireCrisp` in before uDepth ~0.7 (flattens the fly-in); re-tilting one of {in-sphere mark, #services wireframe} without the other.

**Never-warp + desaturate + align (2026-06-25 follow-up).** The PRESENTED brandmark shape (flat rest + landed wireframe) must never warp/wobble — only the wind-blown flight may move particles. So: the corridor sim is PINNED (`PINNED_CORRIDOR_FORCES` = flow/turbulence 0, returnStrength full) — the morph is vertex-shader-driven off the pinned home, so pinning doesn't touch the transition; the rasterizer guarantees ≥ count unique candidates (no seed-wrap duplicates → no doubled-dot hot spots); and `vCrisp` (high at flat rest AND landed) tightens + stills + flattens size-variance so the shape reads clean. `PRODUCTION_BLENDING` is `normal` (not additive): additive accumulation over the dense mark clipped to a vivid yellow, normal blending settles at the true muted `#caa554` and matches the normal-blend #services wireframe. `TARGET_HALF = 0.5` (the group's full half-extent = the sphere's apparent radius) so the wireframe edges align with the sphere. Pitfalls: re-enabling sim flow/turbulence for the corridor (re-warps); reverting to additive (re-saturates); padding the seed/target buffers with zeros instead of wrapping (origin "photon" cluster).

**Unification — one object into #services (2026-06-25 follow-up).** The corridor core IS the #services centerpiece; it no longer cross-dissolves into a SECOND brandmark in a separate canvas. Gated by `UNIFIED_SERVICES_ARMILLARY` (`components/landing/home-v2/unifiedServicesInstrument.ts`). The core does NOT fade out at the dive (`handoffFade` is now `docked ? 1 : servicesAmbient ? servicesAmbientLevel : 1` — full through the dock + ambient, fading only as `#continuum` nears). The #services orbit armillary is a CHILD of the core's group via `CorridorArmillary` (renders `HologramOrbits` + `DEFAULT_ORBITS` in the SAME corridor canvas, so orbits depth-interleave with the mark and inherit its billboard/drift/scale); a `pointerLookRef` wrapper tilts mark+orbits toward the cursor when parked. Scan anchors publish to `hologramConnectorStore` only once parked; `ServicesStage` writes `activeServiceId` to that store as the cross-tree bridge and stops mounting its own R3F canvas (`showServicesCanvas = useHologramCanvas && !UNIFIED_SERVICES_ARMILLARY`). The standalone `ServicesHologramScene`/`VolumetricBrandmarkArtifact` remain the lab harness. Color flows from `lib/home-v2/goldPalette.ts` (`HANDOFF_*` LOCKED `#caa554`/`#e9c97a` for the handoff; `TENSOR_*` for landed/orbits/#services; `SPHERE_GOLD` for the substrate-sphere shells). Pitfalls: reintroducing a separate #services canvas/crossfade (the dissolve the user rejected); ungating the armillary/anchors from `recT`/dissipate (orbits leak into the corridor proper); breaking the mobile/reduced-motion DOM+SVG fallback (it must stay — the corridor never docks there).
