# Prompt log

Every prompt that was sent, including the ones that failed. Superseded prompts
stay; the record of what did not work is most of the value.

The prompts themselves are not retyped here — they are in each wave's
`MANIFEST.jsonl`, verbatim, one line per draw, beside the output on Drive.
Print any of them with:

```bash
python tools/wave.py --wave <wave> --print-prompt <TYPE>-<subject>
```

This file records what changed and why.
