# Memory

What this ship knows. One line per entry, dated, oldest first within a
section. An entry is a ruling, never an argument: the argument lives where the
pointer says. When this file nears 120 lines, compress: merge and shorten,
remove arguments, keep every ruling and every pointer.

    - YYYY-MM-DD [tag] what was decided, learned or ruled out -> where the evidence is

Two tags and no more. `[breakthrough]`: a thing worked and was confirmed, and
a skill, rule or reference changed because of it. `[verdict]`: someone said
the work was good, or not; the line points at the file holding their words
verbatim and never restates them. A tagged line always carries a pointer.
Everything else is untagged. `tools/memory.py --check` reads this file, and the
home port extracts the tagged lines first.
