# The subjects

Each subject as an object: what it is, what it is made of, which parts it has
and how many, and which file is the truth about it. Nothing here is a
judgment about how a picture should look; it says what is true about the
thing. The paths live in `armada.toml [subjects.*]` and `DRIVE.md`; this is
the prose the prompts and the grader draw on.

Read the nouns off the identity reference, not off a spec sheet, and say
which. A part you cannot see in any reference does not exist for the model
either.

## Template

### <subject key> — <name>

- **What it is:** one sentence a stranger would use.
- **Anatomy:** the parts, each with its count. One body. One spout. One
  handle. The model duplicates what is not counted.
- **Colour, material, finish (CMF):** body, rim, glazed and unglazed areas,
  marks.
- **Marks:** where the brand's mark sits, how large, in what finish.
- **Scale:** against something a room contains.
- **Identity truth:** the file, its pixel size, and what it shows and hides.
- **Detail views:** role → file → the geometry only that view carries.
- **Governed parts:** cut-outs the client says never to redraw or merge.
  Attach; do not describe.
- **Not yet in the pack:** what is missing, and what that blocks.
