### 3. Rules

- **Rule 1: Terminal Aesthetic.** The visual foundation should draw heavily from retro-futuristic, code-based environments.
  - _Quote:_ "...it's really built in a terminal interface."
- **Rule 2: Cohesive Design Language.** Different sections can serve different functions, but 2D and 3D elements must look like they belong to the exact same operating system.
  - _Quote:_ "...the 2D ones, they need to feel as part of the same design language... how we combine the 2D with the 3D."
- **Rule 3: Restraint with 3D.** 3D should be used for hero artifacts and major conceptual models, not for basic UI elements or small functional icons.
  - _Quote:_ "Not everything has to be 3D... we need little icons. That shouldn't be like a 3D thing, right? It should be more like a 2D thing."
- **Rule 4: Mathematical Precision.** Diagrams should feel exact, clean, and data-driven rather than purely decorative.
  - _Quote:_ "...super clean. It's more mathematical."
- **Rule 5: Thematic Metaphor.** The overarching visual theme is "navigation" and "technical manuals," implying exploded views, clear labeling, and structural clarity.
  - _Quote:_ "...our storytelling, our leitmotif, it's navigation. And in navigation you have like technical manuals."

### 4. The Core Proposition

**Visualizing the Flow (Adoption to Automation):**
The core proposition is visualized as a linear, horizontal 3D artifact built along a central axis.

- **The Encoded Layer:** The center of the diagram represents the "Thoughtform brand mark"—a waveform/particle cluster that acts as the intelligence configuration. This is the "thought form" itself ("Form into thought").
- **Adoption (Input):** The left side of the axis represents the "upstream" flow. This is where the team's way of working is adopted and fed into the central encoded layer.
- **Automation (Output):** The right side of the axis represents the "downstream" flow. This is where the encoded layer is "plugged into your organization" to execute and automate tasks.
- **Movement:** The flow is communicated through "simple animations" (like the rotating rings and pulsing waves shown in the local host example) moving across this left-to-right axis.

**What it must NOT be:**

- It must **not** be circular or closed-loop; it is explicitly described as a linear axis (left = upstream, center = brand mark, right = downstream).
- It must **not** be a disjointed mix of styles ("it can't be like too discombobulated either").
- It must **not** use heavy 3D models for the granular, step-by-step UI frames (like "creative strategy, creative production"); those must be represented by 2D icons that share the same terminal/hairline aesthetic.
